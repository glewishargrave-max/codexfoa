Identity · Base Class
Sixteen base classes

Every character is built on a base class that sets their key mechanic. The sixteen: Archer, Barbarian, Bard, Binder, Cleric, Fighter, Knight, Monk, Psychic, Reaper, Rogue, Runemage, Spellsword, Teknixian, Witch, Wizard.

Identity · Subclass
Ten subclasses, fifteen duals

Each base class branches into 10 subclasses — like the Scout — each specializing in a different area, plus 15 dual classes that fuse it with another base class.

Statistics · Attributes
Attributes drive everything

Each of the eight attributes feeds a set of base stats — and sets the thresholds a character must meet to unlock passives, skills, and abilities. For Archers, Dexterity is the primary attribute, and the one that governs damage.

Statistics · Damage
Damage by action type

Every action draws on a different damage value — ranged, melee, or magic — depending on how it is delivered. Samson is specialized in ranged, so his ranged value leads.

Abilities · Action System
Three actions, three power levels

Every ability carries a power level — Major, Move, or Minor. On each turn a character spends three actions, one of every level: a Major, a Move, and a Minor.

Passives · Overview
Always-on, tiered

Always-on bonuses that taper with diminishing returns — but each pays out more at higher tiers.

Mechanic · Aim
Aim sharpens every shot

The Archer's key mechanic. Every attack that lands improves Samson — scaled to that attack's accuracy. Abilities can require, consume, or generate aim.

Mechanic · Scouted Abilities
A signature per subclass

Each subclass has its own signature mechanic. The Scout's scouted abilities are stronger on the first turn of a combat wave.

Identity · Roster
A roster of sixteen, four to a battle

You command sixteen characters in all, fielding four of them in any given battle. Each is bound to one of the base classes — Samson to the Archer.

Identity · Weapon
A weapon to each class

Every class is paired with a signature weapon — its own stats and its own function in a fight. The Scout draws the Short Bow.

Skills · Class Skills
The Archer's own

Belong to the Archer line alone. Preliminary Action (Damage All) strikes every enemy before battle; Aim Amount (First Attack) builds extra aim on the opening attack.

Skills · Parent
Conditioned on momentum

The Momentum parent adds an extra effect when the unit starts its turn with momentum.

Skills · Effects
Momentum-fed stat boosts

Enhance Accuracy and Enhance Dodge, attached to momentum, grant enhanced stats when the unit starts with enough momentum.

Skills · Modifiers
Tune the attached skill

Enhance modifiers raise the effect of the skills they attach to; Threshold modifiers lower the momentum needed to trigger them.

Passive · Capstone
Every class has one

A capstone passive any character can equip — improving or granting passive abilities like those the class expresses.

Statistics · Mana
A resource that builds

Shared by every character. Mana starts each battle near zero and accumulates over time, opening up more powerful abilities.

Progression · Level
Level sets the baseline

Level rises with Talent and fixes a unit's general stats — base damage, health, defense, and resistance — before passives and attributes modify them further.

Progression · Talent
Earned in battle, spent freely

Talent is the experience won from battle, spent to develop any of the four facets. Passives, Abilities, and Skills — and new classes — each also need a training manual to purchase.

Statistics · Speed
Speed sets the tempo

In the count-to-battle system, Speed governs how quickly — and how often — a unit gets to act.

Ability · Adroit Momentum
Accuracy and momentum, stacked

A pinpoint modifier scales damage by accuracy; a momentum modifier, by excess timer count.

Ability · Flanking Shot
Opens a target up

Inflicts flanked — lowering dodge and raising the damage rogues deal.

Ability · Screens
A closing move

Common to archers; used last in the turn to generate aim and grant buffs like damage shield.
